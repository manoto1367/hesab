# حساب

برنامهٔ فارسی (راست‌چین) برای ثبت هزینه روستاها: تاریخ شمسی، متراژ، هزینه متراژ، کرایه و نوع ماشین، هزینه‌های متفرقه، گزارش روزانه و داشبورد تعاملی. همهٔ مبالغ به تومان و زیر هر مبلغ به حروف نوشته می‌شود.

## ساختار
- `index.html` — کل برنامه (یک فایل)
- `supabase/schema.sql` — جدول `hesab_records` و سیاست‌های RLS

## اتصال به Supabase
- ورود/ثبت‌نام با ایمیل و رمز؛ هر کاربر فقط رکوردهای خودش را می‌بیند (RLS).
- اتصال به پروژه در پس‌زمینه انجام می‌شود (آدرس و کلید عمومی در ابتدای اسکریپت `index.html`: `DEF_URL` و `DEF_KEY`). برای پروژهٔ دیگر، `supabase/schema.sql` را در آن پروژه اجرا و این دو مقدار را عوض کنید.
- اگر در Supabase گزینهٔ «Confirm email» روشن است، بعد از ثبت‌نام ایمیل را تأیید کنید.
- بدون ورود، برنامه با ذخیرهٔ محلی مرورگر کار می‌کند.

## انتشار روی GitHub Pages
1. یک مخزن جدید بسازید و این فایل‌ها را در آن آپلود کنید.
2. در Settings ← Pages شاخهٔ `main` و پوشهٔ root را انتخاب کنید.
3. آدرس سایت پس از چند دقیقه فعال می‌شود.
4. در Supabase ← Authentication ← URL Configuration آدرس سایت خود را به Site URL اضافه کنید.
